## 1. 벡터
벡터는 여러 숫자를 한 줄로 묶은 값입니다.

**x = [2, 3, 5]**

집 한 채의 정보를 다음과 같이 표현할 수 있습니다.

**x = [84, 3, 12]**

각 값은 다음을 나타낼 수 있습니다.

- 84: 집의 면적
- 3: 방 개수
- 12: 지하철역까지의 거리

값이 3개이므로 3차원 벡터입니다.

---
## 2. 행렬
행렬은 숫자를 행과 열로 배열한 것입니다.
```text
A = [
  [1, 2, 3],
  [4, 5, 6]
]
```

이 행렬은 다음과 같습니다.

- 행: 2개
- 열: 3개
- 크기: 2 × 3
- shape: (2, 3)

머신러닝 데이터에서는 일반적으로 다음처럼 해석합니다.
```text
행 = 데이터 또는 샘플
열 = 특성
```

---
## 3. 벡터 덧셈

**a = [1, 2]**
**b = [3, 4]**

각 위치의 값을 더합니다.
```text
a + b
= [1 + 3, 2 + 4]
= [4, 6]
```

---
## 4. 스칼라배
벡터의 모든 값에 같은 숫자를 곱합니다.
```text
3 × [1, 2]
= [3 × 1, 3 × 2]
= [3, 6]
```

---
## 5. 벡터의 크기
벡터 **v = [3, 4]**의 크기는 다음과 같습니다.
```text
‖v‖
= √(3² + 4²)
= √25
= 5
```

일반적인 벡터의 크기는 다음과 같이 계산합니다.
```text
‖x‖₂ = √(x₁² + x₂² + ⋯ + xₙ²)
```

---
## 6. 내적
다음 두 벡터가 있다고 가정합니다.

**a = [1, 2, 3]**
**b = [4, 5, 6]**

내적은 같은 위치의 값을 곱한 뒤 모두 더합니다.
```text
a · b
= 1 × 4 + 2 × 5 + 3 × 6
= 4 + 10 + 18
= 32
```

내적의 결과는 벡터가 아니라 숫자 하나입니다.

---
## 7. 내적과 선형회귀
선형회귀 모델은 다음과 같습니다.
```text
ŷ = w₁x₁ + w₂x₂ + w₃x₃ + b
```

벡터로 표현하면 다음과 같습니다.
```text
ŷ = wᵀx + b
```

예를 들어 다음과 같은 입력과 가중치가 있습니다.
```text
x = [10, 3, 2]
w = [0.5, 4, -1]
```

내적은 다음과 같습니다.
```text
wᵀx
= 0.5 × 10 + 4 × 3 + (-1) × 2
= 5 + 12 - 2
= 15
```

편향이 3이라면 다음과 같습니다.
```text
ŷ = 15 + 3
  = 18
```

---
## 8. 코사인 유사도
내적을 이용하면 두 벡터의 방향이 얼마나 비슷한지 측정할 수 있습니다.
```text
cos θ = (a · b) / (‖a‖ × ‖b‖)
```

- 1에 가까움: 같은 방향
- 0에 가까움: 서로 직각
- -1에 가까움: 반대 방향

---
## 9. 행렬 덧셈
```text
A = [
  [1, 2],
  [3, 4]
]

B = [
  [5, 6],
  [7, 8]
]
```

같은 위치의 원소끼리 더합니다.
```text
A + B = [
  [1 + 5, 2 + 6],
  [3 + 7, 4 + 8]
]

= [
  [6, 8],
  [10, 12]
]
```

행렬 덧셈은 두 행렬의 shape이 같아야 합니다.

---
## 10. 원소별 곱
```text
A ⊙ B = [
  [1 × 5, 2 × 6],
  [3 × 7, 4 × 8]
]

= [
  [5, 12],
  [21, 32]
]
```

NumPy에서는 `A * B`로 계산합니다.

---
## 11. 행렬곱

행렬곱은 다음 조건을 만족해야 합니다.
```text
(m × n) @ (n × p) → (m × p)
```

왼쪽 행렬의 열 개수와 오른쪽 행렬의 행 개수가 같아야 합니다.

예:
```text
(2 × 3) @ (3 × 4) → (2 × 4)
```

가운데 숫자인 3이 같으므로 계산할 수 있습니다.

반면 다음 계산은 불가능합니다.
```text
(2 × 3) @ (4 × 2)
```

가운데 숫자인 3과 4가 다르기 때문입니다.

---
## 12. 행렬곱 계산 예시
```text
A = [
  [1, 2],
  [3, 4]
]

B = [
  [5, 6],
  [7, 8]
]
```

첫 번째 행과 첫 번째 열을 내적합니다.
```text
1 × 5 + 2 × 7 = 19
```

첫 번째 행과 두 번째 열:
```text
1 × 6 + 2 × 8 = 22
```

두 번째 행과 첫 번째 열:
```text
3 × 5 + 4 × 7 = 43
```

두 번째 행과 두 번째 열:
```text
3 × 6 + 4 × 8 = 50
```

결과는 다음과 같습니다.
```text
A @ B = [
  [19, 22],
  [43, 50]
]
```

---
## 13. 행렬곱 순서
행렬곱은 일반적으로 순서를 바꾸면 결과가 달라집니다.
```text
AB ≠ BA
```

또한 `AB`는 가능하지만 `BA`는 불가능할 수도 있습니다.

---
## 14. 전치행렬
전치행렬은 행과 열을 서로 바꾼 것입니다.
```text
A = [
  [1, 2, 3],
  [4, 5, 6]
]
```

A의 shape은 `(2, 3)`입니다.

전치행렬 Aᵀ는 다음과 같습니다.
```text
Aᵀ = [
  [1, 4],
  [2, 5],
  [3, 6]
]
```

Aᵀ의 shape은 `(3, 2)`입니다.

---
## 15. 여러 데이터의 선형회귀
데이터가 3개이고 특성이 2개라면 입력 행렬은 다음과 같습니다.
```text
X = [
  [1, 2],
  [3, 4],
  [5, 6]
]
```

X의 shape:
```text
(3, 2)
```

가중치 벡터는 다음과 같습니다.
```text
w = [
  [0.5],
  [2]
]
```

w의 shape:
```text
(2, 1)
```

행렬곱 결과는 다음과 같습니다.
```text
(3 × 2) @ (2 × 1) → (3 × 1)
```

실제 계산:
```text
Xw = [
  [1 × 0.5 + 2 × 2],
  [3 × 0.5 + 4 × 2],
  [5 × 0.5 + 6 × 2]
]

= [
  [4.5],
  [9.5],
  [14.5]
]
```

편향이 1이라면 다음과 같습니다.
```text
ŷ = Xw + 1

= [
  [5.5],
  [10.5],
  [15.5]
]
```

---
## 16. 신경망의 행렬 연산
신경망의 한 층은 기본적으로 다음 계산을 수행합니다.
```text
Z = XW + b
```

예를 들어:
```text
X shape: (32, 10)
W shape: (10, 5)
```

행렬곱은 다음과 같습니다.
```text
(32 × 10) @ (10 × 5) → (32 × 5)
```

따라서 결과 Z의 shape은 다음과 같습니다.
```text
(32, 5)
```

---
## 17. 이미지의 shape
컬러 이미지의 shape이 다음과 같다고 가정합니다.
```text
(720, 1280, 3)
```

각 숫자의 의미는 다음과 같습니다.
- 720: 높이
- 1280: 너비
- 3: 색상 채널

PyTorch에서 이미지 32장을 한 번에 처리한다면 다음과 같은 shape을 사용할 수 있습니다.
```text
(32, 3, 224, 224)
```

- 32: 이미지 개수
- 3: 색상 채널
- 224: 높이
- 224: 너비

## 19. NumPy 연산 구분
```python
A * B
```

원소별 곱입니다.
```python
A @ B
```

행렬곱입니다.
```python
np.dot(a, b)
```

# 핵심 용어 정리

|   |   |   |
|---|---|---|
|영어|한국어|의미|
|Scalar|스칼라|숫자 하나|
|Vector|벡터|여러 숫자를 한 줄로 표현|
|Matrix|행렬|숫자를 행과 열로 표현|
|Tensor|텐서|다차원 배열|
|Dimension|차원|축 또는 벡터 성분의 개수|
|Shape|형태|각 축의 크기|
|Row|행|가로 방향|
|Column|열|세로 방향|
|Element|원소|배열 안의 개별 값|
|Norm|노름|벡터의 크기|
|Unit Vector|단위벡터|크기가 1인 벡터|
|Dot Product|내적|같은 위치를 곱한 뒤 합산|
|Matrix Multiplication|행렬곱|행과 열의 내적으로 계산|
|Element-wise Product|원소별 곱|같은 위치의 원소끼리 곱함|
|Transpose|전치|행과 열을 교환|
|Identity Matrix|단위행렬|곱셈에서 1 역할을 하는 행렬|
|Inverse Matrix|역행렬|곱했을 때 단위행렬이 되는 행렬|
|Linear Independence|선형 독립|서로 중복되지 않는 방향|
|Broadcasting|브로드캐스팅|크기가 다른 배열 간 확장 연산|
|Batch|배치|한 번에 처리하는 데이터 묶음|
