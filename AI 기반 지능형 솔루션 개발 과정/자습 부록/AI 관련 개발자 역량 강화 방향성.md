#자습

---
코드 작성으로는 비개발자와 차별점이 없음
무엇을 판단했고 어떻게 문제를 정의했는가가 중요하다

# 1. 문제 정의 능력
특정 주제를 가지고 프로젝트를 진행할 때,
예를 들어 '군중 위험 감지'가 주제라면
위험을 어떻게 정의할 것인가가 중요
여기서부터는 개발자의 영역

# 2. 시스템 설계 능력
= 큰그림 그리기
시스템의 전체적인 흐름을 설계할 수 있는가

# 3. 데이터를 의심하는 습관
예를 들어 YOLO 결과를 분석할 때,
탐지한 결과를 그대로 믿으면 안 된다

가려짐, 조명, 그림자, 원근감 등 요소 고려
오탐이 생길 수 있고 이를 어떻게 줄일 것인지를 고민해야 함

ByteTrack으로 Tracking
여러 프레임 평균
confidence Threshold 조정
ROI(관심 영역) 지정

이러한 판단이 프로젝트의 완성도를 크게 높임

# 4. AI를 도구로 쓰는 능력
그냥 "YOLO로 사람 탐지하는 코드 짜줘" 보다는
"YOLO 추론 결과를 Redis Pub/Sub으로 전달하고 FastAPI WebSocket을 통해 Dashboard를 실시간 업데이트하는 구조를 설계해줘"
이런 식으로 AI에게 정확한 문제를 잘 정의하고 분해해서 요청하는 능력 필요

# 5. "서비스"를 만드는 능력
실제 고객이 사용하는 건 모델이 아니라 서비스
"서비스처럼" 제공해야 한다

YOLO -> Bounding Box만 딸랑 보여주지 말고,

YOLO -> 위험 판단 - 관리자 알림 - 사고 로그 저장 - GPT가 상황 요약 - 대시보드 통계 - PDF 보고서 자동 생성

이런 구조로 흐름 짜기
