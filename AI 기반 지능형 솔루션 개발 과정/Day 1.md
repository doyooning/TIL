# RPA
UiPath가 가장 대중적, 근데 비쌈

다른 RPA로는 MS의 PowerAutomate 한번 찍먹
비용적인 부분에서 대안책

기존의 프로세스를 자동화하는 것이기 때문에 개발 시간이 짧음

RPA는 항상 개발자가 1명... 팀 협업과 거리가 멀다

On-Premise 버전은 로컬에서 작동하는 느낌이고
Cloud 버전은 로그인 과정이 있음

RE Framework(Robotic Enterprise)를 가장 많이 사용
따로 포트폴리오 만들거면 이거로 열심히 만들기

# 시작하기
프로젝트 설명에는 기능, 누가 언제 개발했는지 + 수정했는지를 보통 기입

UiPath에서 제공하는 익스텐션에 한해 업무 자동화 가능
ex) Java 프로젝트에서 자동화 적용 시 Java 익스텐션 설치
미제공하는 분야는 적용이 매우매우 힘들다

### UiPath 자동화 플랫폼 세부 기능:
1. UiPath Studio(개발 도구)
2. UiPath Assistant(실행 보조 도구)
3. UR(Unattended Robot, 무인형 / 비협업로봇)
   사람 개입 없이 작업
4. AR(Attended Robot, 유인형 / 협업로봇)
   사용자와 동일 PC에서 작업, 사용자가 개입

# 액티비티

**플로우차트**
복잡한 관계가 구성될 때는 플로우차트 그리기

**시퀀스**
여러 가지 액티비티를 하나의 묶음 단위로 유지
그룹화같은 기능임

**Use Excel File**
엑셀 파일 참조하기
참조할 파일의 주소 입력
'다음으로 참조'는 이 파일을 참조할 때 어떤 이름으로 찾을 것인지를 지정
긴 참조 주소 대신 사용하는 목적, 임의로 지정 가능

템플릿 파일을 작업하는 경우에는 덮어써서 저장하면 안되므로
변경 내용 저장에는 체크 해제

없으면 생성 기능은 MS 관련 프로그램을 만들 때,
Create File로 만들면 오류가 남(아마 라이센스 문제?)
때문에 이 부분을 체크해서 생성해야 함

**For Each Excel Row**
엑셀 파일의 한 행마다 실행
반드시 Use Excel File 내부 실행에 넣어주어야 함

CurrentRow는 한 행(데이터 1개 단위)
'범위 내' 속성은 엑셀 시트를 지정

엑셀에서 해당 범위를 드래그하여 범위 지정
헤더가 포함되어있지 않으면 헤더 포함에 체크 해제

하나의 컬럼을 Item이라고 부름
현재 행(사업자번호)의 컬럼을 만들어 주려면

```
CurrentRow.Item("사업자번호")
CurrentRow.ByField("사업자번호")
```

**Write Line**
로그찍기와 동일한 기능
텍스트를 출력함

Break와 Continue
프로그래밍에서의 반복문 표현과 동일

### 레코딩 연습
엑셀에서 매크로 등록하는 것과 방법 동일
자동 로그인을 구현할 때,
로그인 창 띄우기 - 아이디 창 클릭 - 비밀번호 창 클릭 - 로그인 버튼 클릭 순으로 레코딩
완료되면 액티비티로 생성되어 있음

**Use Browser**
해당 브라우저에서 하위 액티비티를 실행함
크롬에서는 하나의 탭 당 하나의 Use Browser 액티비티를 생성해야 함
Use File도 동일하게 하나의 파일당 하나의 액티비티

**앵커**
어느 정보를 기반으로 할 것인지 위치를 정해주는 것
어떤 데이터를 지정했을 때, 이 데이터가 무엇에 해당하는 것인지를 앵커를 지정함으로써 해결

**Get Text**
선택한 타겟에서 텍스트 추출
-> 복사 + 붙여넣기

복사와 붙여넣기가 한 개의 액티비티에 존재하므로 액티비티 배치할 때 위치 고려해야 함

엑셀에 추출한 텍스트를 붙여넣을 때:
'텍스트 값' 부분에 `Excel.sheet("sheet1").Cell("A1")` 방식으로 입력

변수에 대입할 때:
'텍스트 값' 부분에 변수명 입력하여 사용
(엘리먼트 아님 !)

### 데이터 테이블
테이블 추출로 DataTable을 생성
추출한 데이터 테이블을 엑셀에 담아주려면 텍스트와 동일한 방식으로 진행

데이터 순서를 바꿔주려면 전체 다 가져오지 말고 하나씩 지정해서 진행

여러 페이지에서 데이터를 가져오려면 토글 버튼 활성화하고 다음 페이지 넘어가는 버튼을 지정

**데이터 테이블을 텍스트로 변환**
Output Data Table as Text 액티비티 사용
추출한 데이터 테이블을 저장할 변수 만들기(데이터 타입: DataTable)
출력할 텍스트를 저장할 변수 만들기(데이터 타입: String)

옵션에서:
입력 - 데이터 테이블 변수, 출력 - 텍스트 변수 지정

결과 확인:
Write Line으로 텍스트 변수 출력
