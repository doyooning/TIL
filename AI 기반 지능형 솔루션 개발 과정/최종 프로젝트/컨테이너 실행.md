# 실행
```bash
docker compose -f .docker/compose.main.dev.yml pull fastapi   # :develop 태그
docker compose -f .docker/compose.main.dev.yml up -d
docker compose -f .docker/compose.llm.dev.yml up -d
```


### 변경사항 적용: face recognition
webapps/fastapi/config/settings.yml


# 로그 조회
```
docker logs -f <컨테이너명>
```

# 이미지
### 조회
```
docker image ls
docker images
```

### 삭제
```
docker rmi IMAGE_ID1 IMAGE_ID2 IMAGE_ID3
```

모든 이미지 삭제:
```
docker rmi $(docker images -q)
```


# 컨테이너
### 삭제
```
docker stop CONTAINER_ID
```

모든 컨테이너 삭제:
```
docker rm -f $(docker ps -aq)
```
