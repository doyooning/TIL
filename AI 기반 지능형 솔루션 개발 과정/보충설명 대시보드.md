# 🔍 보충설명 대시보드

노트를 작성하다가 **추가 조사가 필요한 부분**에 `#보충설명` 태그를 달아두면,
이 곳에 자동으로 모여 한눈에 확인하고 바로 이동할 수 있습니다.

> 조사를 마치면 해당 위치의 내용을 채우고 `#보충설명` 태그를 지우세요.
> 그러면 아래 목록에서 자동으로 사라집니다. (남은 개수 = 남은 할 일)

## 📌 미해결 항목

```query
tag:#보충설명 -path:"보충설명 대시보드"
```

## 사용법

- 각 결과를 클릭하면 해당 노트의 위치로 이동합니다.
- **표기 규칙**: 반드시 붙여써서 `#보충설명` (공백 넣으면 `#보충 설명`으로 끊겨 태그가 깨짐).
- 이 노트를 **북마크(Bookmarks)** 에 등록하거나 사이드바에 고정해두면 빠르게 열 수 있습니다.
