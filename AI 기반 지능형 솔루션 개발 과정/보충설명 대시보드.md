# 🔍 보충설명 대시보드

노트를 작성하다가 **추가 조사가 필요한 부분**에 `#보충설명` 태그를 달아두면,
이 곳에 자동으로 모여 한눈에 확인하고 바로 이동할 수 있습니다.

> 조사를 마치면 해당 위치의 내용을 채우고 `#보충설명` 태그를 지우세요.
> 그러면 아래 목록에서 자동으로 사라집니다. (남은 개수 = 남은 할 일)

## 📌 미해결 항목

```query
tag:#보충설명 -path:"보충설명 대시보드"
```

## 사용법

- 각 결과를 클릭하면 해당 노트의 위치로 이동합니다.
- **표기 규칙**: 반드시 붙여써서 `#보충설명` (공백 넣으면 `#보충 설명`으로 끊겨 태그가 깨짐).
- 이 노트를 **북마크(Bookmarks)** 에 등록하거나 사이드바에 고정해두면 빠르게 열 수 있습니다.

---

## ✍️ 정리 규칙

작성 중 추가 조사가 필요하면 그 자리에 `#보충설명` 플래그만 달아둔다. 조사를 마치면 아래 둘 중 하나로 **해소하고 태그를 지운다.**

- **사소한 내용** → 그 자리에 바로 내용을 채우고 `#보충설명` 삭제.
- **긴/개념적 내용** → 해당 주제 폴더의 `보충 설명/` 안에 별도 노트를 작성하고, 원래 자리에 `[[링크]]`를 걸고 `#보충설명` 삭제.
  - 예: 컴퓨터 비전 관련이면 `컴퓨터 비전/보충 설명/OO.md`
  - 별도 노트에도 출처 태그(`#KDT` 등)를 달면 MOC의 `### 보충 설명` 섹션에 자동 정리된다.

> 핵심: `#보충설명`(태그) = 아직 안 한 것 → 대시보드에 남음. `[[링크]]` = 완료된 것.
> 둘의 상태가 겹치지 않게, 해소되면 태그는 반드시 제거한다. 완료 이력은 git이 기록한다.
