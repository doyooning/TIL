# 과제: 견적서 취합 및 단가비교표 작성
### 동적으로 버튼 동작하기
해당 요소를 화면에서 선택하고, Selector 통해서 태그 요소 확인
태그 중에서 동적으로 일정한 규칙을 가지고 변동하는 요소를 변수로 대체
ex) `tableRow='2'` -> `cstr(int_index + 2)`
참고로 태그 수정시에는 타입 일치해야 하므로 숫자 -> 문자 변환 필요

페이지네이션이 있는 경우,
데이터테이블 추출로 전체 데이터에 대해 반복을 돌릴 수 있도록 만들어주고
각 Row에 대해 반복 규칙을 적용해줌:
>CurrentIndex는 기본적으로 0부터 시작,
페이지네이션은 최대 8이고,
만약 `tableRow='2'` 부터 시작한다고 하면
`str_index = cstr((int_index Mod 8) + 2)`
이런 식으로 반복문 전용 인덱스 변수를 만들어서 운영하면 됨
추가로 `int_index Mod 8 = 7`일 때에는 페이지네이션 버튼 클릭도 해주면 굿
(0일 때로 하면 시작부터 다음 페이지로 넘겨버림..)
