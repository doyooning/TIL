# AI 엔지니어링
### 프롬프트 엔지니어링

**프롬프트 잘 짜기**
Context: 어떤 상황에서
Role: 어떤 정체성을
Task: 구체적으로 무엇을
	작업량 정하는 것이 중요(ex. 500자)
Constraint: 어떤 형식이나 기준으로

위 4가지를 명확하게 설계

**종류**
Instruction Prompt(지시형)
	: 작업 지시 중심 프롬프트
Contextual Prompt(문맥형
	: 상황, 배경 제공으로 자연스러운 결과 유도
Few-shot Prompt(예시형)
	: 예시를 함께 제시하여 AI가 학습 패턴을 모방하게 함
Chain of Thought Prompt(사고의 사슬형)
	: 단계적 추론 유도
Multi-modal Prompt(멀티모달형)
	: 텍스트, 이미지, 영상 등 처리

### 컨텍스트 엔지니어링
1. 정확성의 극대화
   맥락 기반 의미 해석
2. 일관성의 확보
   사용자 스타일, 과거 대화, 도메인 규칙을 지속 반영
3. 의사결정의 지능화
   환경, 목표, 제약 조건까지 고려하는 고차원적 응답 생성

**핵심 구성 요소**
	1. 사용자 맥락
	2. 직업, 전문성 수준
	3. 표현 스타일
	4. 최근 사용 패턴
	5. 해결하려는 문제의 난이도와 우선순위

**작업 해결**
작업 유형(글쓰기, 분석, 코딩 등),
요구되는 구조/형식/길이, 제약조건)
도메인 맥락: 분야별 언어적 패턴
시스템 맥락: Retrieval, 메모리, API 연동 등 시스템 환경
상황 맥락: 목적의 방향성 변화

**콘텍스트가 핵심 전략인 이유?**
- AI는 텍스트가 아니라 의미를 다뤄야 함
- 결과물의 품질은 문맥 충실도로 결정
- 강력한 AI 시스템일수록 콘텍스트 관리가 결정적
- AI의 진화 방안은 지율적 맥락'

콘텍스트 핵심 전략의 철학
인간 중심성 
의미 기반 지능
지속적 학습

### AI FDE(Forward Deployed Engineer)
팔란티어사의 FDE 구조

데이터 엔지니어링 패러다임:
ETL/ELT vs. AI 기반 자율 데이터 엔지니어링

**AI FDE의 구조 및 워크플로우 시스템**
의도 분석
	사용자 자연어 명령을 파운드리 작업 단위로 분해
맥락 로드
	필요한 데이터셋, 온톨로지 스키마, 정책만을 선택적으로 로드(컨텍스트 오염 방지)
실행 및 루프
	Action: 코드 생성 및 데이터 변환
	Observe: 결과값 확인, CI/CD 체크 통과 여부 검증
	Feedback: 실패 시 스스로 디버깅 후 재시도
	Governance Proposal: 변경 사항 브랜치 단위 생성, 인간 승인(PR) 대기

**기업 현장에서 AI FDE**
도메인 지식의 내재화
기술 장벽의 제거

**FDE의 역할**
의미론적 계층(Semantic Layer)
	상품, 고객, 구매와 같은 비즈니스 객체 중심의 설계
인간 개입 루프(Human-in-the-loop)
	마지막 단계에서 인간 엔지니어가 결과를 승인하고 튜닝하는 거버넌스 구조
데이터 계보(Data Lineage)
	AI가 만든 데이터 흐름이 어디서 왔는지 추적 가능해야 신뢰 가능함

**AI FDE: 데이터와 비즈니스를 잇는 자율형 신경망**
```
데이터 소스 -> AI FDE 엔진(LLM + Rule Engine) -> 온톨로지
							|
				비즈니스 레이어(Workshop)
							|
				현장 의사결정: 보험, 제조, 마케팅
```

AI FDE 기반 엔지니어링:
- 자연어 기반 에이전트 지시
- 의미 중심(Object-based)
- 실시간 적응형 업데이트
- 현장 실무자(Citizen Developer) 중심

도메인별 FDE 전략: 제조와 영업의 변혁
1) 제조 기업: 에러율 최소화와 생산성 향상 전략
	데이터 기반 예방 정비를 지향
2) 영업/마케팅/보험: 고객 심리와 성과 극대화 전략
	데이터로 고객의 심리를 읽는 것이 핵심
	고객 심리 관리: 고객 구매 이력, SNS 반응 등을 통합하여 고객 온톨로지를 구축
	보험 분석/설계: 고객 재무 데이터와 건강 정보를 온톨로지에 매핑
	영업 효율화: 일정 관리와 리드 점수화를 자동화, 영업 인력은 고객과의 대화에 집중하도록 함

### Ontology
**의미론적 연결**
데이터는 쏟아져 나오나, 서로의 맥락을 이해 못 하는 데이터 사일로 현상
현대적 온톨로지는 개별 데이터를 고립된 수치가 아닌, 상호 의존적인 관계로 연결

**AI의 자율적 추론과 맥락 이해**
현대 AI는 빅데이터를 기반으로 확률 계산, 데이터가 없는 예외적인 상황이나 복잡한 비즈니스 로직이 얽힌 환경에서는 한계가 있음
온톨로지는 도메인 전문가가 가진 암묵적 법칙과 제약 조건을 기계가 이해하게 하여 추론 정확도를 비약적으로 높일 수 있음
온톨로지에 정의된 규칙을 바탕으로 상황을 논리적으로 판단, 인간 개입 없이 안전하고 전략적인 의사결정을 내릴 수 있는 판단력을 가짐

**현장 밀착형 지식 체계**
범용적 지식이 아닌 현장 특화 지식에 초점
AI FDE는 현장에서 실시간으로 발생하는 데이터를 옹ㄴ톨로지에 매핑, 시스템이 현장의 최신 변화를 지식 체계에 즉각 반영하도록 설계
살아있는 지식 구조체

**인간과 AI의 가교(Bridge)**
온톨로지는 인간과 AI가 서로의 언어를 주고받는 소통 언어
