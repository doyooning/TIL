# YOLO를 활용한 마스크 착용 판별

### 이미지 라벨링
이미지가 어디에 속하는지 라벨링 작업을 해야 함
마스크 착용인지, 미착용인지를 라벨링

### YOLO에 넣고 돌려
train/images에 해당 이미지 넣고,
train/labels에 해당 이미지의 라벨링 파일(YOLO는 txt)을 넣어줌

epochs는 300으로 했는데 적당히 잘 나오는 듯

### 훈련 결과 확인
결과는 runs/train/yolov5s_results 안에 생성됨

### 타겟 이미지 준비
test/images에 판별할 이미지 투입

### 타겟 영상 준비
test에 mp4 영상 투입

### 판별 결과 확인
결과는 runs/detect/exp 안에 생성됨


conf는 0.4 정도가 잘 잡히긴 함
여기서 더 낮추면 너무 바운딩 박스가 막 잡힐수도 있고,
더 올리면 더 엄격해지긴 한데 데이터 많으면 엄격한 것도 필요할 수 있을듯
