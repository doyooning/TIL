# 선형 회귀
K-최근접 이웃 알고리즘의 단점:
훈련 세트를 벗어난 새로운 샘플이 등장하면 이상한 값을 예측하게 됨

### Linear Regression
선형 회귀 모델을 훈련하고(fit), 점수를 얻고(score), 예측함(predict)

```
y = ax + b
```
 lr 객체에 저장됨
 a : coef_
 b : intercept_
기울기를 계수(coefficient) 또는 가중치(weight)라고 부름

### 다항 회귀
선형 회귀의 직선 그래프는 0 아래로 내려감
현실의 데이터(무게, 길이 등)는 불가능
최적의 '곡선'을 찾자

```
y = ax^2 + bx + c
```

2차방정식의 그래프를 그리려면 특성을 제곱한 항이 훈련 세트에 추가되어야 함
-> 길이를 제곱한 항을 새로 만들어준다

새롭게 등장하는 샘플들도 어느 정도 예측 가능한 모델이 됨

# 특성 공학과 규제

### 다중 회귀
여러 개의 특성을 사용한 선형 회귀
특성이 2개면 `타깃 + 특성1 + 특성2`로 3차원 공간이 형성됨

특성 공학 = 기존 특성을 사용하여 새로운 특성을 뽑아내는 작업

### 변환기 in sklearn
변환기(transformer)는 사이킷런에서 제공하는 특성을 만들거나 전처리를 위한 클래스
`PolynomialFeatures()` 클래스로 만든다

fit()으로 먼저 학습하고 그 다음 transform()

2개의 특성을 가진 샘플은 6개의 특성이 만들어짐
`[1, 자기자신(각 2개), 자기자신제곱(각 2개), 서로곱한값(1개)]`
(직접 확인 방법: `poly.get_feature_names_out()`)

`include_bias` : 절편을 추가할 것인지
사이킷런의 선형 모델은 자동으로 절편을 추가하므로
False로 설정해준다

### 다중 회귀 모델 훈련
선형 회귀 모델 훈련과 똑같음
다만 특성이 여러 개

1. 클래스 호출
2. fit(train, train타겟) 한다
3. score(train, train타겟), score(test, test타겟) 확인

`degree` : 차수 설정
최대차항을 정해줄 수 있는데 높을수록 특성이 많아짐

근데 특성의 개수가 너무 많으면 훈련 세트를 거의 완벽하게 학습하나,
훈련 세트에 너무 과대적합되어 테스트 세트에서 폭망함

### 규제
ML모델이 훈련 세트를 너무 과도하게 학습하지 못하도록 막는 것
모델이 훈련 세트에 과대적합되지 않게 방지
선형 회귀 모델의 경우 특성에 곱해지는 계수(또는 기울기)의 크기를 작게 만드는 일

계수 값의 크기가 서로 많이 다르면 공정하게 제어되지 않으므로, 정규화가 필요
-> `StandardScalar()` 클래스 활용

### 릿지 회귀
선형 회귀 모델에 규제를 추가한 모델
계수를 제곱한 값을 기준으로 규제 적용
일반적으로 릿지 선호

### 라쏘 회귀
선형 회귀 모델에 규제를 추가한 모델
계수의 절댓값을 기준으로 규제 적용

라쏘 모델 훈련시 ConvergenceWarning 발생할 수 있음
라쏘 모델은 최적의 계수를 찾기 위해 반복 계산을 수행, 
지정한 반복 횟수가 부족할 때 경고 발생
라쏘 모델 생성시에 max_iter 매개변수를 10000 정도로 지정해놓으면 됨

라쏘 모델이 0으로 만든 계수값의 개수를 바탕으로 최적의 특성 개수 판단 가능
`print(np.sum(lasso.coef_ == 0))`
(`np.sum()` 함수는 True = 1, False = 0으로 인식하여 덧셈 가능)

모델에 주입한 특성 개수 - 해당 반환값 = 라소 모델이 사용한 특성


두 알고리즘 모두 계수의 크기를 줄임, 라쏘는 0을 만들 수도 있음

두 모델에서 규제의 양을 임의로 조절 가능
alpha 매개변수로 조절
크면 강도 세짐, 계수 값을 더 줄이고 과소적합 유도 / 작으면 선형 회귀 모델과 유사해져 과대적합 유도

==적절한 alpha값을 찾는 방법==
alpha값에 대한 R^2 값의 그래프를 그려본다
: alpha 리스트를 만들어놓고(0.001 ~ 100) 반복문으로 돌려서 모델 훈련하고 평가

훈련-테스트 그래프가 가장 가까워진 지점의 alpha값을 선택
