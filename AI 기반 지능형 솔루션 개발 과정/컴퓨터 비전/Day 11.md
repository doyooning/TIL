# CNN 개요
## CNN(Convolutional Neural Network)
가장 널리 쓰이는 딥러닝 기법
이미지 특징을 직업 학습, 추출하는 단계 포함

데이터 전처리 -> 학습 ->결과 도출

객체 탐지에 YOLO를 사용 , CNN 모델 사용

## 컨볼루션 층
### 컨볼루션
: 이미지 필터링을 위한 연산
ex) 3x3 수직선 검출용 필터를 이용한 에지 이미지 획득

입력 이미지와 필터에 컨볼루션을 적용하여 특징맵을 얻음
입력 이미지(5x5) -> 필터(3x3) -> 컨볼루션 결과 이미지(3x3) = 특징맵(feature map)

**컨볼루션의 효과**
입력 이미지에 필터의 특징이 있는지 확인

### 활성화 함수
**렐루(ReLU) 함수**
픽셀값 범위 재조정 효과(음수가 없도록 함)
특정값이 큰 유효 픽셀들을 찾기 위함

## 풀링
세로 및 가로 방향으로 이미지 크기를 줄이는 연산
일반적으로 최대 풀링(Max Pooling)을 사용
최대 풀링: 보통 2x2 영역에서 가장 큰 값을 선택

**최대 풀링의 효과**
특징맵의 크기를 줄여 계산량을 감소
강인성 향상

## CNN 구조 이해
### 컨볼루션 층을 신경망 관점에서 이해
CNN은 입력 데이터가 첫 번째 은닉층의 뉴런에 완전히 모두 연결되어 있지 않음
입력 이미지의 픽셀 정보를 저장하고 있는 입력층 노드의 작은 일부 영역만이 
은닉층(컨볼루션 층)의 노드(뉴런) 한 개와 연결됨

은닉층이 하나 = 일반적인 ML
은닉층이 더 있다 = 딥러닝

은닉층은 한 개의 특징맵으로 구성됨

### 풀링을 신경망 관점에서 이해
특징맵에 렐루 함수를 적용 후 최대 풀링 적용
-> 반타작

신경망 관점에서 해석하면
24x24 노드를 갖는 특징맵 -> 12x12 특징맵

### 컨볼루션 층을 여러 개의 특징맵으로 구성
보통 은닉층은 다양한 종류의 특징을 추출하기 위해 여러 개의 특징맵으로 구성함
이 경우, 특징맵들에 서로 다른 필터(=가중치들)가 적용됨

은닉층(=컨볼루션 층)을 32개의 특징맵으로 구성한다면

필터가 5x5, 입력층이 28x28일 때:
은닉층 -> 24x24x32
풀링 적용 -> 12x12x32

필터를 거쳐서 어떤 특징점을 찾고자 하는 목적임


### 필터(=가중치) 학습 및 시각화
학습 전 필터는 무작위 값으로 초기화되고 있어, 필터값에 규칙성이 없음
학습을 마친 후 필터는 규칙성 있는 형태를 갖게 됨
-> 입력 이미지에 대해 의미 있는 특징을 추출할 수 있음
