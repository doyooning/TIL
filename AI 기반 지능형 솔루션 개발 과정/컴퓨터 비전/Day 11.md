# CNN 알고리즘
## 컨볼루션 층
### 컨볼루션
: 이미지 필터링을 위한 연산
= 합성곱 연산
ex) 3x3 수직선 검출용 필터를 이용한 에지 이미지 획득

입력 이미지와 필터에 컨볼루션을 적용하여 특징맵을 얻음
입력 이미지(5x5) -> 필터(3x3) -> 컨볼루션 결과 이미지(3x3) = 특징맵(feature map)

**컨볼루션의 효과**
입력 이미지에 필터의 특징이 있는지 확인

### 활성화 함수
**렐루(ReLU) 함수**
픽셀값 범위 재조정 효과(음수가 없도록 함)
특정값이 큰 유효 픽셀들을 찾기 위함

## 풀링
세로 및 가로 방향으로 이미지 크기를 줄이는 연산
일반적으로 최대 풀링(Max Pooling)을 사용
최대 풀링: 보통 2x2 영역에서 가장 큰 값을 선택

**최대 풀링의 효과**
특징맵의 크기를 줄여 계산량을 감소
강인성 향상

## CNN 구조 이해
### 컨볼루션 층을 신경망 관점에서 이해
CNN은 입력 데이터가 첫 번째 은닉층의 뉴런에 완전히 모두 연결되어 있지 않음
입력 이미지의 픽셀 정보를 저장하고 있는 입력층 노드의 작은 일부 영역만이 
은닉층(컨볼루션 층)의 노드(뉴런) 한 개와 연결됨

은닉층이 하나 = 일반적인 ML
은닉층이 더 있다 = 딥러닝

은닉층은 한 개의 특징맵으로 구성됨

### 풀링을 신경망 관점에서 이해
특징맵에 렐루 함수를 적용 후 최대 풀링 적용
-> 반타작

신경망 관점에서 해석하면
24x24 노드를 갖는 특징맵 -> 12x12 특징맵

### 컨볼루션 층을 여러 개의 특징맵으로 구성
보통 은닉층은 다양한 종류의 특징을 추출하기 위해 여러 개의 특징맵으로 구성함
이 경우, 특징맵들에 서로 다른 필터(=가중치들)가 적용됨

은닉층(=컨볼루션 층)을 32개의 특징맵으로 구성한다면

필터가 5x5, 입력층이 28x28일 때:
은닉층 -> 24x24x32
풀링 적용 -> 12x12x32

### 풀링 추가
풀링을 적용했을 때 은닉층의 특징맵 개수는 변하지 않음
(각 특징맵의 가로 세로 크기만 절반으로 줄이기 때문)

### 필터(=가중치) 학습 및 시각화
학습 전 필터는 무작위 값으로 초기화되고 있어, 필터값에 규칙성이 없음
학습을 마친 후 필터는 규칙성 있는 형태를 갖게 됨
-> 입력 이미지에 대해 의미 있는 특징을 추출할 수 있음

필터를 거쳐서 어떤 특징점을 찾고자 하는 목적임

# CNN 특성
### 국소적 연결(Local Connectivity)
**Fully Connected Neural Net**
은닉층의 노드가 수많은 픽셀값을 한번에 입력받아 뉴런을 전부 동등하게 취급
-> 이미지가 가진 2차원의 형상 정보가 제대로 반영되기 어려움

**Locally Connected Neural Net**
은닉층의 각 노드마다 입력 이미지의 다른 영역에 대한 정보를 처리함
-> 눈 코 입 등의 구조적 정보를 유지할 수 있어 이미지 이해 능력을 향상시킴

### 계층적 처리
입력과 가까운 층: 입력에 비해 분석 영역이 좁음
- 엣지와 같이 매우 작은 부분에 대한 정보를 추출하도록 설계됨
  컨벌루션 층을 한 번 거치면서 이미지의 사이즈가 작아져 상대적으로 분석 영역이 넓어짐
- 눈, 코, 입과 같은 파트 정보들을 추출함
  자동차처럼 매우 작은 부품들을 조립하고,
  이를 이용해서 바퀴와 같은 파트로 만들어내는 것과 비슷함

풀어야 할 복잡한 문제를 여러 층이 분담해서 처리하므로,
각 층 입장에서는 단순화된 학습 문제를 더 쉽게 풀어내는 효과를 얻을 수 있음

```
Convolution Layer -> Feature Extraction
...
Fully Connected Layer -> Classification

Pixels -> Edges -> Object Parts -> Object Models
(Raw <--------------------------------> Abstract)
```

Low-Level Feature
-> Mid-Level Feature
-> High-Level Feature
-> Trainable Classifier
