# 퍼셉트론
뉴런의 원리를 인공적으로 모델링한 알고리즘
신경망의 기본 단위
입력 - 출력 -> 다음 뉴런(노드)에 전달

신호를 입력받는 부분,
계산이 이루어지는 노드,
계산된 값을 출력하는 부분 으로 구성

w(weigh) : 가중치
b(bias) : 절편(=편향)
절편은 어떤 경우에도 항상 하나다

가중합: 입력값과 가중치의 곱을 모두 더한 뒤 바이어스를 더함

활성화 함수:
- 시그모이드(Sigmoid): 가중합이 크면 1에 가까운 값 출력, 작으면 0에 가까운 값 출력
- 계단함수: 가중합이 크면 1, 작으면 0

### 학습과 손실함수
학습
= 예측값과 정답의 차이가 최소가 되도록 각 가중치 값과 바이어스 값을 결정하는 과정

학습 단계
예측값을 정답과 비교하면서 신경망을 점점 더 정확하게 만드는 과정

예측 단계
학습이 완료된 신경망에 새로운 데이터를 입력하면 정확한 예측값을 출력할 가능성이 커짐
(항상 맞힌다는 보장은 없음)
