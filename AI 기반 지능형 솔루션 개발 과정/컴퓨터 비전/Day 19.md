# 군집 알고리즘

군집 : 비슷한 샘플끼리 모으는 작업
클러스터 : 군집 알고리즘에서 만든 그룹

비슷한 샘플끼리 어떻게 모으는가?

### k-평균
이미지에 어떤 사물이 들어 있는지 알지 못하는 경우, 평균값을 어떻게 구할 수 있을까?
-> k-평균 군집 알고리즘
평균값을 클러스터 중심 또는 센트로이드라고 함

k-평균 알고리즘 작동 방식
1. 무작위로 k개의 클러스터 중심을 설정
2. 각 샘플에서 가장 가까운 클러스터 중심을 찾아 해당 클러스터의 샘플로 지정
3. 클러스터에 속한 샘플의 평균값으로 클러스터 중심을 변경
4. 클러스터 중심에 변화가 없을 때까지 2번으로 돌아가 반복

### KMeans
sklearn.cluster의 KMeans에 구현되어 있음
transform() 메서드는 훈련 데이터 샘플에서 클러스터 중심까지 거리로 변환해 줌

### 최적의 k 찾기
클러스터 중심을 특성 공학처럼 사용해 데이터셋을 저차원으로 변환 가능
가장 가까운 거리에 있는 클러스터 중심을 샘플의 예측값으로 사용할 수 있음

실전에서는 클러스터 개수조차 알 수 없는데, 어떻게 지정해주는가?
완벽한 방법은 없으나, 가장 대표적인 방법은 **엘보우 방법**

k-평균 알고리즘은 클러스터 중심과 클러스터에 속한 샘플 사이의 거리 측정 가능
-> 거리의 제곱 합 = **이너셔(inertia)**
(클러스터에 속한 샘플이 얼마나 가깝게 모여있는가)

# 주성분 분석(PCA)
### 차원과 차원 축소
제일 중요한 특성 하나 잡고, 그 다음으로 중요한 특성 하나 잡아서
2개의 특성으로 분석한다(2차원 구성)

특성을 많이 잡을수록 데이터가 뭉그러지기 때문에 딱 2개만 잡기
원본 데이터를 주성분에 투영하여 특성의 개수를 줄일 수 있음

### 원본 데이터 재구성
특성을 대폭 줄이게 되면 어느 정도 손실이 발생할 수밖에 없음
그러나 최대한 분산이 큰 방향으로 데이터 투영, 원본 데이터를 상당 부분 재구성할 수 있음

### 설명된 분산
주성분이 원본 데이터의 분산을 얼마나 잘 나타내는지 기록한 값(explained variance)
첫 번째 주성분의 분산이 가장 크고, 주성분이 늘어날수록 분산값이 줄어드는 그래프
그래프가 거의 평탄해지는 부분까지가 적절한 주성분 개수

### 단순 알고리즘과 함께 사용하기
PCA 클래스 + 알고리즘(로지스틱 회귀 모델 등..)

### 주성분 분석으로 차원 축소
PCA 클래스는 자동으로 설명된 분산을 계산하여 제공
