```
① 빈 테이블 (5분)

② 컵만 놓기 (5분)

③ 컵+접시 (5분)

④ 노트북+컵 (5분)

⑤ 책+컵 (5분)

⑥ 가방+노트북 (5분)

⑦ 사람 앉기 (5분)

⑧ 사람 잠깐 자리 비우기 (5분)

⑨ 친구가 지나가기 (5분)

⑩ 여러 사람이 지나가기 (5분)
```

| 시나리오              | 상태              | 목적       |
| ----------------- | --------------- | -------- |
| 빈 테이블             | AVAILABLE       | 기준 데이터   |
| 사람만 앉음            | OCCUPIED        | 사람 탐지    |
| 사람 + 노트북 + 컵      | OCCUPIED        | 복합 객체    |
| 사람 퇴장, 컵·노트북만 남음  | BELONGINGS_ONLY | 핵심 시나리오  |
| 컵과 접시도 반납 후 퇴장    | AVAILABLE       | 상태 전환 검증 |
