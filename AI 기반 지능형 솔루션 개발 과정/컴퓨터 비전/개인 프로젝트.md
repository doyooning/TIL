# 이미지 전처리

# YOLO 훈련 결과
### Attempt 1
훈련 데이터: 카페 실제 데이터 약 100개(상황 이미지)
파라미터 설정:
img 416, batch 16, epochs 150
테스트 데이터: 카페 실제 데이터 3장 우선 확인
결과: 3장 모두 no-detection

### Attempt 2
훈련 데이터: 카페 실제 데이터 약 100개(상황 이미지)
파라미터 설정:
img 416, batch 10, epochs 200
테스트 데이터: 카페 실제 데이터 3장 우선 확인 + 웹에서 찾은 음료(cup) 및 케잌(dish) 사진
결과: 3장 모두 no-detection, 오탐(케잌 사진을 사람으로 오인)

### Attempt 3
훈련 데이터: 카페 실제 데이터 약 100개(상황 이미지)
-> 데이터 라벨링 범위 재설정
파라미터 설정:
img 640, batch 10, epochs 200
테스트 데이터: 카페 실제 데이터 3장 우선 확인 + 웹에서 찾은 음료(cup) 및 케잌(dish), 가방(bag) 사진
결과: 3장 중 2장 정확히 탐지, 1장 오탐(뒷배경 사람을 컵으로 오인), 웹 사진은 전부 no-detection

### Attempt 4
훈련 데이터: 카페 실제 데이터 약 100개(상황 이미지) + 웹 크롤링 이미지 약 40장(객체 보완)
파라미터 설정:
img 640, batch 10, epochs 200
테스트 데이터: 카페 실제 데이터 3장 우선 확인
결과: 3장 모두 정확히 탐지(오탐한 상황 해결됨)

샘플 영상으로 테스트 실시:
빈 테이블 -> 1명 등장, 컵과 접시 -> 1명 추가
결과: 이상 없이 예상대로 탐지
