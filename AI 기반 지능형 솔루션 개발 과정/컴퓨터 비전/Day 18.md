# 로지스틱 회귀
대표적인 이진 분류 모델
확률이 되려면 0~1 또는 0~100% 사이 값이 되어야 하므로
z가 아주 큰 음수일 때 0, 아주 큰 양수일 때 1이 되도록 바꾸면 됨
-> 시그모이드 함수, 로지스틱 함수

![[Pasted image 20260731143437.png]]

### LogisticRegression
로지스틱 회귀 모델
이진 분류의 경우 시그모이드 함수의 출력이 0.5보다 크면 양성, 작으면 음성 클래스로 판단
(sklearn은 0.5일 때 음성으로 판단)

이진 분류는 불리언 인덱싱 후 로지스틱 회귀 모델 훈련

### 다중 분류 수행
LogisticRegression은 기본적으로 릿지 회귀와 같이 계수의 제곱을 규제함(L2 규제)
규제 제어 변수는 C, 작을수록 규제가 커짐, 기본값은 1

클래스가 7개, 특성이 5개인 다중 분류에서의 선형 방정식은?
`lr.coef_.shape`와 `lr.intercept_.shape`를 확인
-> `(7, 5) (7,)`
-> z를 7개 계산한다는 뜻, 클래스마다 z값을 계산하고 가장 높은 z값을 출력하는 클래스가 예측 클래스가 됨

확률은?
이진 분류: 시그모이드 함수 사용, z를 0~1 사이 값으로 변환
다중 분류: 소프트맥스 함수 사용, 7개의 z값을 확률로 변환

**소프트맥스 함수**
여러 개의 선형 방정식의 출력값을 0~1 사이의 확률로 압축, 전체 합이 1이 되도록 만들어줌
최댓값에 높은 확률을 할당하면서도 다른 값에도 작은 확률을 부여함(soft한 max)
= 정규화된 지수 함수

```LaTeX
e_sum = e^z1 + e^z2 + ...
s1 = e^z1 / e_sum, s2 = e^z2 / e_sum, ...
```

scipy.special에서 softmax() 함수 사용 가능
axis: 계산할 축 지정, 1 = 각 행에 대해 계산

### 정리
K-최근접 이웃 모델은 확률 출력 가능하나 이웃 샘플 클래스 비율이므로
항상 정해진 확률만 출력하는 한계

대표적인 분류 알고리즘인 로지스틱 회귀로 확률 출력
선형 회귀처럼 선형 방정식을 사용하나, 계산값을 그대로 출력하는 것이 아니라 0~1 사이로 압축

이진 분류에서는 하나의 선형 방정식을 훈련, 출력값을 시그모이드 함수에 통과시켜 0~1 사이 값 생성
다중 분류에서는 클래스 개수만큼 방정식을 훈련, 출력값을 소프트맥스 함수를 통과, 전체 클래스 합 = 1 유지

# 확률적 경사 하강법
### 점진적 학습
기존의 훈련 데이터에 새로운 데이터를 추가하여 모델을 계속 다시 훈련하는 것이 바람직
단점은 시간이 지날수록 데이터가 늘어나게 됨
훈련한 모델을 버리지 않고 새로운 데이터에 대해서만 조금씩 더 훈련한다면?
-> 점진적 학습, 대표적인 알고리즘은 확률적 경사 하강법

확률적 = 랜덤하게, 무작위로
경사 하강법 = 기울기를 내려오는 방법

가장 빠른 길은 경사가 가파른 길,
가장 가파른 길을 천천히 조금씩 내려온다

훈련 세트를 사용하여 가장 가파른 길을 찾아냄
딱 하나의 샘플만을 훈련 세트에서 랜덤하게 골라 가장 가파른 길을 찾음

모든 샘플을 사용해도 산을 다 내려오지 못했다면, 다시 처음부터 시작
에포크(epoch): 훈련 세트를 한 번 모두 사용하는 과정

여러 개의 샘플을 사용한다 = **미니배치 경사 하강법**
전체 샘플을 사용한다 = **배치 경사 하강법**

### 손실 함수
ML 알고리즘이 얼마나 예측을 못하는가를 측정한 기준
연속적인 손실 함수를 만들기 위해 로지스틱 손실 함수를 사용

`-(예측 x 타깃)`
샘플 타깃이 음성 클래스(0)일 경우에는 곱하면 무조건 0이므로
타깃을 마치 양성 클래스(1)처럼 바꾸고, 예측값도 양성 클래스에 대한 예측처럼 바꿈
-> `1 - (예측 확률)` 한 다음 곱하고 음수로 바꿈

![[Pasted image 20260731174110.png]]

이진 분류: **로지스틱 손실 함수**
다중 분류: **크로스엔트로피 손실 함수**

### SGDClassifier
SGD(Stochastic Gradient Descent)
**확률적 경사 하강법**을 제공하는 대표적 분류용 클래스
모델을 이어서 훈련할 때는 `partial_fit()` 메서드 사용

loss 매개변수는 손실 함수의 종류를 지정
`loss='log_loss'` : 로지스틱 손실 함수로 지정해줌
-> 다중 분류의 경우 SGDClassifier에 위처럼 지정하면 클래스마다 이진 분류 모델을 생성
= 하나를 양성 클래스로 두고, 나머지를 모두 음성 클래스로 두는 방식
= **OvR(One versus Rest)** 방식

loss의 기본값은 'hinge'

# 결정 트리
설명하기 쉬운 모델
데이터를 잘 나눌 수 있는 질문을 추가해서 분류 정확도를 높임

리프 노드에서 가장 많은 클래스가 예측 클래스가 됨

### 불순도
지니 불순도(Gini impurity)
DecisionTreeClassifier의 criterion 매개변수의 기본값으로 설정되어 있음
(criterion은 노드에서 데이터를 분할할 기준을 정함)

```
지니 불순도 = 1 - {(음성 클래스 비율)^2 + (양성 클래스 비율)^2}
```

어떤 노드의 두 클래스의 비율이 정확히 1/2씩이라면 지니 불순도는 0.5로 최악임
노드에 하나의 클래스만 있다면 지니 불순도는 0으로 가장 작음(=순수 노드)

루트 노드를 부모 노드라고 하면,
왼쪽 / 오른쪽 노드가 자식 노드
불순도 차이 계산:

```
부모의 불순도 - {(좌노드 샘플 수) / (부모 샘플 수)} * 좌노드 불순도
			 - {(우노드 샘플 수) / (부모 샘플 수)} * 우노드 불순도
```

부모와 자식 노드 사이의 불순도 차이를 **정보 이득(Information Gain)** 이라 함

`criterion='entropy'`를 지정하여 **엔트로피 불순도** 사용 가능
노드 클래스 비율을 사용하나, 제곱이 아니라 밑이 2인 로그를 사용하여 곱함
보통은 지니랑 차이가 크지 않음

# 교차 검증과 그리드 서치
### 검증 세트
훈련 세트 약 60%, 검증 세트 약 20%, 테스트 세트 약 20%

### 교차 검증
교차 검증을 이용하면 안정적인 검증 점수를 얻고 훈련에 더 많은 데이터를 사용 가능
검증 세트를 떼어내어 평가하는 과정을 여러 번 수행
이 점수를 평균하여 최종 검증 점수 산출

3-폴드 교차 검증
```
훈 훈 검
훈 검 훈
검 훈 훈

훈x2 : 모델 훈련, 검 : 모델 평가
모델 평가 3건 검증 점수 평균
```
-> k-폴드(겹) 교차 검증
보통은 5-폴드, 10-폴드를 많이 사용

sklearn의 `cross_validate()`는 5-폴드가 기본값
이 함수는 훈련 세트를 섞어 폴드를 나누지 않으므로,
교차 검증시 훈련 세트를 섞으려면 분할기(splitter)를 지정해야 함
기본적으로 회귀 모델일 경우 KFold 분할기 사용,
분류 모델일 경우 타겟 클래스를 골고루 나누기 위해 StratifiedKFold를 사용

### 하이퍼파라미터 튜닝
사용자가 지정해주어야 하는 파라미터
이를 자동으로 수행하는 기술을 AutoML이라고 함
sklearn에서 제공하는 그리드 서치

GridSearchCV 클래스는 하이퍼파라미터 탐색과 교차 검증을 한 번에 수행
cv 매개변수 기본값은 5(5-폴드)

n_jobs : 병렬 실행에 사용할 CPU 코어 수를 지정 가능
(기본값 1, -1로 하면 시스템의 모든 코어 사용)

`best_estimator_` : 훈련된 모델이 저장되어 있는 속성
`best_params` : 그리드 서치로 찾은 최적의 매개변수가 저장된 곳

# 트리의 앙상블
### 정형 데이터와 비정형 데이터
정형 데이터 : CSV, DB,  엑셀 등 저장 가능
비정형 데이터: DB나 엑셀로 표현하기 어려운 객체

**랜덤 포레스트**
: 결정 트리를 랜덤하게 만들어 결정 트리의 숲을 생성,
우리가 입력한 데이터에서 랜덤하게 샘플 추출, 훈련 데이터 생성

RandomForestClassifier

자체적으로 모델 평가 점수 산출

부트스트랩에 포함되지 않고 남는 샘플

### 엑스트라 트리

엑스트라 트리가 무작위성이 조금 더 크기 때문에 더 많은 결정 트리를 훈련해야 함

### 그레이디언트 부스팅
Gradient Boosting
깊이가 얕은 결정 트리를 사용하여 이전 트리의 오차를 보완하는 방식으로 앙상블
과대적합에 강하고 높은 일반화 성능 기대
경사 하강법을 사용

분류 : 로지스틱 손실 함수 사용
회귀 : 평균 제곱 오차 함수(MSE) 사용

그레이디언트 부스팅은 결정 트리를 계속 추가하며 가장 낮은 곳을 찾아 이동
랜덤 포레스트보다 일부 특성에 더 집중

subsample 매개변수
: 트리 훈련에 사용할 훈련 세트의 비율
기본값은 1.0, 1보다 작으면 훈련 세트의 일부를 사용
