# 로지스틱 회귀
대표적인 이진 분류 모델
확률이 되려면 0~1 또는 0~100% 사이 값이 되어야 하므로
z가 아주 큰 음수일 때 0, 아주 큰 양수일 때 1이 되도록 바꾸면 됨
-> 시그모이드 함수, 로지스틱 함수

### LogisticRegression
로지스틱 회귀 모델
이진 분류의 경우 시그모이드 함수의 출력이 0.5보다 크면 양성, 작으면 음성 클래스로 판단
(sklearn은 0.5일 때 음성으로 판단)

이진 분류는 불리언 인덱싱 후 로지스틱 회귀 모델 훈련

### 다중 분류 수행
LogisticRegression은 기본적으로 릿지 회귀와 같이 계수의 제곱을 규제함(L2 규제)
규제 제어 변수는 C, 작을수록 규제가 커짐, 기본값은 1

클래스가 7개, 특성이 5개인 다중 분류에서의 선형 방정식은?
`lr.coef_.shape`와 `lr.intercept_.shape`를 확인
-> `(7, 5) (7,)`
-> z를 7개 계산한다는 뜻, 클래스마다 z값을 계산하고 가장 높은 z값을 출력하는 클래스가 예측 클래스가 됨

확률은?
이진 분류: 시그모이드 함수 사용, z를 0~1 사이 값으로 변환
다중 분류: 소프트맥스 함수 사용, 7개의 z값을 확률로 변환

**소프트맥스 함수**
여러 개의 선형 방정식의 출력값을 0~1 사이의 확률로 압축, 전체 합이 1이 되도록 만들어줌
최댓값에 높은 확률을 할당하면서도 다른 값에도 작은 확률을 부여함(soft한 max)
= 정규화된 지수 함수

```LaTeX
e_sum = e^z1 + e^z2 + ...
s1 = e^z1 / e_sum, s2 = e^z2 / e_sum, ...
```

scipy.special에서 softmax() 함수 사용 가능
axis: 계산할 축 지정, 1 = 각 행에 대해 계산

### 정리
K-최근접 이웃 모델은 확률 출력 가능하나 이웃 샘플 클래스 비율이므로
항상 정해진 확률만 출력하는 한계

대표적인 분류 알고리즘인 로지스틱 회귀로 확률 출력
선형 회귀처럼 선형 방정식을 사용하나, 계산값을 그대로 출력하는 것이 아니라 0~1 사이로 압축

이진 분류에서는 하나의 선형 방정식을 훈련, 출력값을 시그모이드 함수에 통과시켜 0~1 사이 값 생성
다중 분류에서는 클래스 개수만큼 방정식을 훈련, 출력값을 소프트맥스 함수를 통과, 전체 클래스 합 = 1 유지

# 확률적 경사 하강법
### 점진적 학습
기존의 훈련 데이터에 새로운 데이터를 추가하여 모델을 계속 다시 훈련하는 것이 바람직
단점은 시간이 지날수록 데이터가 늘어나게 됨
훈련한 모델을 버리지 않고 새로운 데이터에 대해서만 조금씩 더 훈련한다면?
-> 점진적 학습, 대표적인 알고리즘은 확률적 경사 하강법

확률적 = 랜덤하게, 무작위로
경사 하강법 = 기울기를 내려오는 방법

가장 빠른 길은 경사가 가파른 길,
가장 가파른 길을 천천히 조금씩 내려온다

훈련 세트를 사용하여 가장 가파른 길을 찾아냄
딱 하나의 샘플만을 훈련 세트에서 랜덤하게 골라 가장 가파른 길을 찾음

모든 샘플을 사용해도 산을 다 내려오지 못했다면, 다시 처음부터 시작
에포크(epoch): 훈련 세트를 한 번 모두 사용하는 과정

여러 개의 샘플을 사용한다 = **미니배치 경사 하강법**
전체 샘플을 사용한다 = **배치 경사 하강법**

### 손실 함수
ML 알고리즘이 얼마나 예측을 못하는가를 측정한 기준
연속적인 손실 함수를 만들기 위해 로지스틱 손실 함수를 사용

`-(예측 x 타깃)`
샘플 타깃이 음성 클래스(0)일 경우에는 곱하면 무조건 0이므로
타깃을 마치 양성 클래스(1)처럼 바꾸고, 예측값도 양성 클래스에 대한 예측처럼 바꿈
-> `1 - (예측 확률)` 한 다음 곱하고 음수로 바꿈
