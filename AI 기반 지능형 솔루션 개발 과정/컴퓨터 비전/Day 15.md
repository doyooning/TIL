# K-최근접 이웃
### KNeighborsClassifier()
k-최근접 이웃을 찾아주는 객체를 만들어 줌

|옵션|기본값|설명|일반적인 권장값|
|---|---|---|---|
|`n_neighbors`|5|사용할 이웃 개수|3~15 (교차 검증으로 결정)|
|`weights`|`"uniform"`|투표 방식|`"uniform"` 또는 `"distance"`|
|`algorithm`|`"auto"`|최근접 탐색 알고리즘|`"auto"`|
|`leaf_size`|30|Tree 성능 조정|기본값 사용|
|`metric`|`"minkowski"`|거리 계산 방식|`"minkowski"` 또는 `"euclidean"`|
|`p`|2|Minkowski 거리의 지수|1(Manhattan), 2(Euclidean)|
|`metric_params`|`None`|거리 함수 추가 옵션|필요 시만 사용|
|`n_jobs`|`None`|병렬 처리 개수|`-1` (가능한 모든 CPU 코어 사용)|
투표 방식 중 uniform은 정정당당하게 각 이웃이 1표씩 행사
distance는 거리가 가까울수록 가중치 부여(가중치는 거리의 역수만큼)

민코프 거리가 기본값인데
p=2가 기본값이므로 유클리드(기하학적 거리, 피타고라스) 거리가 기본값
-> 두 좌표값의 차를 제곱한 값을 모두 더하고 루트 씌워줌

맨하탄 거리는 도시 블록처럼 직각 모양으로 계산하는 방식(도로 거리와 유사)
-> 두 좌표값의 차에 절댓값 적용하고 모두 더해줌

# K-최근접 이웃 회귀
### 과대적합
훈련 세트 점수가 좋았으나 테스트 세트 점수가 안좋은 경우
훈련 세트에만 잘 맞는 모델이라 실전에 잘 안 맞는 케이스

### 과소적합
테스트 세트가 훈련 세트보다 점수가 높거나
두 점수가 모두 너무 낮은 경우
모델이 너무 단순해서 훈련 세트에 적절하게 훈련되지 않은 경우

가장 좋은 결과는 훈련 세트 그래프에 테스트 세트 그래프가 따라붙으면서 그 격차가 좁아지는 그래프
적정선에서 훈련은 그만해야 함
