# 공식 Partner Academy 커리큘럼 → 시험 범위 매핑

출처: **Anthropic Partner Academy** (<https://anthropic-partners.skilljar.com>)
시험 가이드 PDF 본문은 로그인이 필요하지만, **prep course의 학습 목표(learning objectives)와 코스 커리큘럼은 공개**되어 있다. 이것이 사실상 가장 신뢰도 높은 출제 범위 신호다.

## 0. 먼저: 자격증은 4종이다 (이름 혼동 주의)

| 자격증 | 약칭 | 가격 | 대상 |
| --- | --- | --- | --- |
| Claude Certified **Associate** – Foundations | **CCA-F** | $99 | "consultants, sellers, and delivery leads who guide customers toward the right Claude use cases" |
| Claude Certified **Developer** – Foundations | **CCDV-F** | $125 | "engineers who build with the Claude API, Claude Code, and Model Context Protocol" |
| Claude Certified **Architect** – Foundations | **CCAR-F** | $125 | "partners who design Claude solutions end to end" |
| Claude Certified **Architect** – Professional | CCAR-P | $175 | Foundations 수료자 |

> ⚠️ **CCA-F는 Architect가 아니라 Associate다.** 흔히 CCA-F와 CCAR-F를 같은 것으로 쓰는 2차 자료가 많은데, Partner Academy 카탈로그상 **별개 시험**이다. CCA-F는 CPN 티어 자격 요건에 포함되지 않는다.

## 2. 모듈별 학습 목표 (원문 기준 요약)

### 모듈 1 — MSO Foundations
1. 토큰이 무엇인지, **컨텍스트 윈도우가 고정 예산**으로 작동하는 방식, **샘플링이 출력을 변하게 하는 이유**, 그리고 **비결정성이 테스트·eval에 갖는 의미**
2. Claude 모델 제품군과 **능력 티어**, 그리고 **"모델 선택"과 "추론 모드(extended thinking) 활성화"를 구분**하기
3. **zero-shot / one-shot / multi-shot** 중 선택하고 예시 추가의 **비용-품질 트레이드오프** 따지기
4. 개발자가 Claude에 접근하는 방식: **SDK vs raw REST**, **동기 vs 스트리밍**, 대량 작업을 위한 **비동기 패턴**

→ [[01 모델 선택과 최적화]] · [[02 Claude API 메커니즘]]

### 모듈 2 — Production-Grade Prompting, Agents & Tool Use
1. **시스템 프롬프트, XML 태그, few-shot 예시, 출력 제약**을 쓴 프로덕션 프롬프트 작성
2. **extended thinking을 언제 켤지**, thinking budget 설정, **도구 사용 턴 전반에서 thinking 블록을 올바르게 처리**하기
3. Claude가 올바르게 선택하는 **도구 스키마 정의**, **도구 사용 루프 구성**, 멀티턴 메시지 블록 처리
4. **스트리밍 응답 소비**, 스트리밍 이벤트를 완전한 콘텐츠 블록으로 조립, **스트림 중단 시 깔끔한 복구**
5. **컨텍스트 엔지니어링**: 컨텍스트 윈도우 관리, 압축(compacting), 히스토리 정리, **서브에이전트 핸드오프**
6. **워크플로 패턴 vs 에이전트 패턴** 선택, 도구와 컨텍스트를 루프에 배선
7. **세션 간 에이전트 메모리 관리** — 영속 저장 패턴과 **메모리 스코프 선택**
8. **이미지·PDF 전송**의 올바른 메시지 블록 구조, **재사용 자산에 Files API**, **대량 워크로드에 Message Batches API**

→ [[05 프롬프트와 컨텍스트 엔지니어링]] · [[04 에이전트와 워크플로]] · [[06 도구와 MCP]] · [[03 애플리케이션 설계와 통합]]

### 모듈 3 — Claude Code, MCP & Integration
1. **explore → plan → code 루프**로 Claude Code를 돌리고, **작업의 위험 수준에 맞는 권한 모드** 선택
2. AI 생성 코드를 읽고 **보정된 신뢰(calibrated trust)** 로 검토하며, **잘못된 판단의 비용이 큰 곳에 인간 검토 게이트**를 둔다
3. **CLAUDE.md, rules 지침 파일, 훅, 서브에이전트**로 지속적 프로젝트 컨텍스트 제공
4. 워크플로를 **Skills, 커스텀 명령, 플러그인**으로 패키징 — **한 번 작성한 Skill이 Claude Code / Messages API / Agent SDK에서 동일하게 동작**하게
5. **tools·resources·prompts를 제공하는 MCP 서버** 구축, 클라이언트-서버 통신에 맞는 **transport 선택**, 누가 로드할지 결정하는 **구성 스코프** 설정
6. 엔터프라이즈 시스템 연결, **규제 고객이 수용할 인증 패턴**, 보안 검토를 통과할 코드 현대화 engagement 스코프 설정

→ [[08 Claude Code 운영]] · [[06 도구와 MCP]]

### 모듈 4 — Production Engineering, Evals & Security
1. 배포 전에 **"done"의 정의를 확정하는 eval 스위트** 작성 + **인간 라벨 사례로 LLM 판정자 채점 보정**
2. **단위 / 기능 / 통합 / 엔드투엔드** 수준에서 회귀를 감지하는 **테스트·추적 계층** 구축
3. **재시도 가능 오류와 종료(terminal) 오류를 구분**해 프로덕션 장애에 견디는 애플리케이션 만들기
4. 여러 에이전트에 걸친 작업에서 **비용·지연 시간·신뢰성 예산** 안에서 운영
5. **프롬프트 인젝션, 탈옥, 신뢰할 수 없는 입력, 스코프된 identity, 노출된 시크릿, 데이터 경계**로부터 통합 방어

→ [[09 평가 테스트 디버깅]] · [[07 보안과 안전]] · [[13 프로덕션 엔지니어링]]

### 모듈 5 — Accelerators & IP Contribution
1. 동작하는 솔루션을 **재사용 가능한 accelerator**로 패키징 — 파라미터화된 에이전트 템플릿, 구성 가능한 MCP 서버, 이식 가능한 eval 스위트
2. 도구·패턴·수정을 **문서화된 채널로 기여**하고 메인테이너가 받아들일 수 있게 준비
3. Claude 워크로드를 어디서 실행할지 선택: **퍼스트파티 API / Amazon Bedrock / Google Vertex AI / 서드파티 플랫폼**, 그리고 **무엇을 버전 관리해 배포할지**
4. 그 플랫폼들을 **지연 시간·컴플라이언스·비용**으로 비교해 조달·보안팀이 승인할 선택 만들기
5. **여러 Claude 배포를 하나의 워크플로로 조율**하고 보안·컴플라이언스 검토를 견딜 **데이터·identity 경계** 설정

→ [[13 프로덕션 엔지니어링]] · [[03 애플리케이션 설계와 통합]]

### "Introduction to Model Context Protocol"
MCP 아키텍처(도구 정의·실행 부담을 내 서버에서 전문화된 MCP 서버로 이전) → **transport에 구애받지 않는 통신과 메시지 타입** → 쿼리에서 클라이언트·외부 서비스를 거쳐 Claude로 돌아오는 전체 흐름 → **Python SDK로 서버 구축** → **MCP Server Inspector로 테스트·디버깅** → **resources 정의와 MIME 타입 처리(JSON/텍스트)** → prompts 구축 → **각 프리미티브를 언제 쓸지 구분** → 자동완성·컨텍스트 주입 등 통합 패턴

### "Claude Code in Action"
**Steer**(plan mode로 스코프, **압축을 유도해 요약이 중요한 걸 남기게**, rewind로 코스 수정) → **Configure**(따르게 되는 lean CLAUDE.md, 반복 절차를 skill로, 권한 모드 선택, **훅**) → **Automate**(routines, headless) → **Verify & Share**(**감독하지 않은 실행은 안 본 만큼 비례해서 검증**, **훅으로 실제 테스트 결과에 턴을 게이팅**, 플러그인)

### "Introduction to Agent Skills"
Skills란 → 첫 skill 만들기 → **구성과 다중 파일 skills** → **Skills vs 다른 Claude Code 기능** → skills 공유 → 문제 해결

### CCAR-F Prep에 포함된 코스 (= Architect 시험의 범위 신호)
AI Fluency: Framework & Foundations / Building with the Claude API / **Claude on Google Cloud** / Claude Code in Action / Claude 101 / **Claude with Amazon Bedrock** / Introduction to Model Context Protocol

> CCAR-F prep에 **Bedrock과 Google Cloud 코스가 명시적으로 들어있다** = 클라우드 플랫폼 배포가 출제 범위다.
