# JaCoCo
자바 애플리케이션의 테스트 품질을 높이기 위해 사용되는 대표적인 오픈소스 코드 커버리지 라이브러리
테스트 실행 시 코드의 몇 %가 실제로 실행되었는지를 측정해 보고서로 제공 
Maven·Gradle과 같은 빌드 도구 및 CI/CD 환경에서 널리 활용

## 주요 특징
- **무료 오픈소스**: EclEmma 팀이 개발한 자바 전용 커버리지 라이브러리
- **다양한 커버리지 지표 제공**:
	- **Line Coverage**: 실행된 코드 라인의 비율
	- **Branch Coverage**: if-else, switch 등 분기 실행 비율
	- **Instruction Coverage**: JVM 바이트코드 명령어 실행 비율
	- **Method Coverage**: 실행된 메서드 개수와 비율
	- **Class Coverage**: 실행된 클래스 개수와 비율
- **빌드 도구와 통합**: Maven, Gradle 플러그인으로 손쉽게 설정 가능
- **리포트 형식**: HTML, XML, CSV 등 다양한 형식으로 결과 제공


# 테스트 커버리지
### 작성
주로 Controller, Service, Repository에 대해 테스트 작성
특정 기능 단위로 테스트 메서드 만들어서 진행
라인과 브랜치로 커버리지 측정하는데, 내가 작성한 부분은 100% 만들어주는 것이 좋음

### 결과 확인

 1. 검증(실패/성공)만 보기
     .\gradlew.bat jacocoTestCoverageVerification -PcoverageScope=account
     account 대신 admin, ai, common, directchat로 바꿔서 실행
  2. 리포트(HTML) 열어 상세 보기
     .\gradlew.bat jacocoTestReport -PcoverageScope=account
     생성 파일: index.html

  추가로 XML 경로:
  - jacocoTestReport.xml

  한 번에 특정 스코프 테스트+리포트까지 보려면:
  .\gradlew.bat test jacocoTestReport jacocoTestCoverageVerification -PcoverageScope=directchat
