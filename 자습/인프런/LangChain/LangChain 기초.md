# LLM 핵심 요약
### 생성형 AI와 토큰(Token)
생성형 AI는 텍스트를 기억하는 것이 아니라, 
학습된 확률 분포를 기반으로 다음에 올 가장 적절한 토큰(단어보다 작은 단위)을 예측하는 *확률 생성기*

### 컨텍스트 윈도우(Context Window) 
모델이 한 번에 처리할 수 있는 최대 토큰의 길이를 의미하며, 모델마다 설정된 제한이 있음

### 생성 파라미터 
결과물의 다양성과 품질을 결정하는 주요 파라미터를 설명

- **Temperature**
  확률 분포의 형태(첨도)를 조절하여 결과물의 일관성이나 창의성을 결정
  분포 평탄화: 낮을수록 보수적, 높을수록 창의적 (0 ~ 1)
  권장값: 분류/추출 0.0, 글쓰기 0.7

- **Top K / Top P** 
  확률이 낮은 토큰을 후보에서 배제하여 출력의 품질을 관리하는 기법

  Top K: 확률이 높은 상위 K개의 단어 안에서 선택
  전체 단어가 100개일 때 K=4이면 상위 4개 단어만 후보군, 나머지 96개는 제외
  Top P: 확률 분포에서 P%의 단어 안에서 선택
  전체 단어가 100개일 때 P=0.8이면 상위 80%(80개) 단어가 후보군, 나머지 하위 20%(20개)는 제외
  권장값: 0.9(보통)

- **max_tokens**
  출력 길이 상한(비용과 직결됨)
  권장값: 작업 별로 빡빡하게 설정

- **stop**
  특정 문자열 만나면 중단
  권장값: 구조화 출력에서 유용
