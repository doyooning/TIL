# RPA
Robotic Process Automation
업무 프로세스에 따라서 로봇이 사람과 똑같이 자동으로 일하는 것

매크로와 비슷하나, 매크로는 엑셀만 사용할 수 있고 소스 코드를 작성해야 함
RPA의 UiPath는 일단 쉽고 다양한 프로그램들을 자동화할 수 있음

강의 자료: https://drive.google.com/drive/folders/1PlNIQw_R5HraNWJa096EbJhwzgDlRKOz?usp=sharing


# 시작하기
로컬에서 UiPath Studio 실행

프로젝트를 생성하고 프로세스 추가
액티비티에서 검색해서 해당하는 액티비티 가져오기

속성에서 필수 항목 채워주고 실행해보기
