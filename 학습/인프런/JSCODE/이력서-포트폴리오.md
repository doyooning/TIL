# 1. 답정너 이론

내가 어떤 사람인지를 어필하는 것이 아닌, 회사에서 뽑고자 하는 인재상인 것처럼 어필

이미 답은 정해져 있다

면접관이 정해놓은 답에 맞춰 어필하기

### 어떤 기준으로 뽑는가

1. 개발 실력이 좋은가(80)
2. 컬쳐핏, 인성, 협업 등(20)

개발 실력이 좋다 = 회사에 들어와서 빠르게 개발에 참여할 수 있는 개발자

자격요건과 우대사항에 최대한 맞춰서 작성

### 프로그래밍 실력 평가 4단계

1. 단순 기능 구현 역량
2. 기술 사용 이유, 특징/장단점, 작동 원리 설명 역량
3. 유지보수하기 좋은 코드 작성(객체지향, 클린코드, 테스트코드 등)
4. 성능 트러블 슈팅 및 개선, 대용량 트래픽 처리 역량

# 4. 오징어게임 이론
나 혼자 게임을 잘하는 것보다 남들보다 게임을 잘 하는 것이 중요
= 내가 개발 실력이 뛰어나지 않더라도 남보다만 잘하면 합격하는 게임

일반적인 내용: 
ex) Spring Boot 사용하여 Restful API 구현, MySQL 활용, AWS로 배포 등등...

이런 내용은 차라리 지우거나 그 안에서 차별점을 찾아야 한다

차별성 있게 살리는 방법
= 구체적으로 기술하기
구체화해도 별로 차별성이 살아나지 않으면 과감하게 삭제

개발은 롤이다.
조금씩 고여가는 분야임
개발 분야 신입의 역량이 점차 높아지고 있음
경쟁자들이 많아질수록 신입 필수 역량이 많아짐
코테, CS + MSA, 메세지큐 등등...
