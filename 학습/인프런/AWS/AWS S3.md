# AWS S3

안전한 파일 저장/검색/삭제 가능

# 버킷
### 폴더
폴더 이름 수정은 쉽지 않으므로 수정해야 한다면 새 폴더 생성하고 기존 폴더 삭제

### 파일(객체)
드래그 앤 드롭으로 파일 또는 폴더 업로드

스토리지 클래스는 스탠다드로 설정

### 공유와 권한
파일 우클릭 후 링크 복붙
링크 그대로 열면 Access Denied(외부에서 열 수 없음)
권한 설정 필요

파일 권한 탭 클릭
내 계정에 대한 권한은 읽기/쓰기 모두 허용이라 접근 가능
'퍼블릭 액세스' 에서 Everyone 그룹의 권한 설정
-> 객체 읽기, 객체 읽기 권한, 객체 쓰기 권한 모두 체크

가장 쉽게는 그냥 파일 우클릭 -> 퍼블릭으로 설정 클릭

# 스토리지 클래스
파일 -> 속성 보면 스토리지 클래스가 있음
파일의 성격에 따라 선택하면 됨

**스탠다드**
가장 무난, 처음 사용하면 그냥 스탠다드

**스탠다드-IA**
IA = Infrequent Access
자주 안사용할 데이터들에 적합(돈을 덜 냄)
자주 접속하면 돈을 더 냄

**단일 영역-IA**
잃어버려도 되는 파일
복제본을 1개만 만들기 때문에 잃어버릴 가능성 있음

**중복 감소**
더 이상 지원 X

 **Amazon Glacier**
 빙하처럼 얼려놓을 데이터
 법적 근거 자료(5년 보관) 등에 해당
 요금 훨씬 저렴, 한 번 꺼낼 때 시간이 오래 걸림

# 요금 체계
###### 스토리지 요금
= 저장 공간을 얼마나 사용했냐

S3 스탠다드:
	처음 50TB/월은 GB당 0.025달러

###### 요청 요금
= 해당 클래스를 얼마나 사용했냐

리전별로 상이
각종 요청별 요금:
	GET, SELECT(다운로드) 등 요청은 1000건 당 0.00035달러
	PUT, COPY, POST(파일을 추가) 등 요청은 1000건 당 0.0045달러

###### 데이터 전송 요금
= 인터넷과 데이터를 얼마나 송수신했냐

클래스 타입에 상관없이 부과
인터넷 -> S3로 데이터 수신: 무료
S3 -> 인터넷으로 데이터 송신: 
	1GB/월 까지는 무료
	그 이상부터는 GB당 0.126달러 부과
