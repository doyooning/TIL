# Supabase에서 DB 구성 및 인가 설정
Supabase는 기본적으로 RLS(Row Level Security)를 권장
근데 이게 되어있으면 DB에 대한 여러가지 요청들이 제한됨
그래서 개발할 때는 해제했다가, 프로젝트 완료시에 RLS + Policy 설정하면 됨

DB 정책은 일단 Select 조회 허용, Insert는 특정 권한 필요 등 설정이 있고
admin 권한 운영하면 해당 권한에 권한 부여(Grant ...) 필요
