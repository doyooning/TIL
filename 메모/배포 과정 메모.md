# 환경 변수
각종 환경 변수를 등록하고 프론트에서 호출함
.env
.env.local
.env.development
.env.development.local 등으로 유지

Vite는 `import.meta.env`에 자동으로 위 환경 변수들을 자동으로 합쳐서 넣음

사용 방법
```js
const apiBase = import.meta.env.VITE_API_BASE_URL || 'http://localhost:8080'  
const oauthBase = import.meta.env.VITE_OAUTH_BASE_URL || window.location.origin
```


# 환경 변수 적용 방법

### EC2에서 `systemd` 서비스로 환경변수 주입

**(1) EC2에 env 파일 만들기**

예: `/opt/deskit/deskit.env`
```bash
sudo mkdir -p /opt/deskit 
sudo nano /opt/deskit/deskit.env
```

내용:
```bash
OPENAI_API_KEY=xxxx 
REDIS_AUTH_TOKEN=xxxx 
AWS_REGION=ap-northeast-2
```

권한(중요):
```bash
sudo chown root:root /opt/deskit/deskit.env sudo chmod 600 /opt/deskit/deskit.env
```

**(2) systemd 서비스에 연결**

`/etc/systemd/system/deskit.service`
```bash
[Unit] Description=deskit app 
After=network.target  

[Service] User=ec2-user 
EnvironmentFile=/opt/deskit/deskit.env 
ExecStart=/usr/bin/java -jar /opt/deskit/deskit.jar 
Restart=always 
SuccessExitStatus=143  

[Install] 
WantedBy=multi-user.target
```

적용:
```bash
sudo systemctl daemon-reload 
sudo systemctl restart deskit 
sudo systemctl status deskit
```

✅ 이 방식이면 `application-prod.yml`에서
```bash
password: ${REDIS_AUTH_TOKEN} 
api-key: ${OPENAI_API_KEY}
```

이렇게 쓰는 게 적용됨

### 2) Docker로 띄운다면: `--env-file` 사용

`docker run --env-file .env.production -p 8080:8080 deskit:latest`

또는 docker-compose:
```yaml
services:
  app:
    env_file:
      - .env.production
```
