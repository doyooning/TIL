###### 1. 최신 모델 사용
당연히...
복잡한 지시 이해 능력이 월등함
최신 모델에 단순하고 명확한 지시를 내리는 게 더 효율적

###### 2. 지시 사항을 앞에 배치
핵심 명령을 프롬프트 맨 앞에, 참고할 데이터 및 컨텍스트는 뒤에 배치

구분자를 사용해 지시와 데이터를 명확하게 구분해주면 더 좋음

**구체적인 묘사**와 **예시 활용** 강조 !!
단순히 "요약해줘"라고 하기보다는 결과물 형태, 길이, 톤&매너 등을 숫자를 활용하여 구체적으로 명시
원하는 출력 형식을 예시로 보여주면 결과 정확도를 높일 수 있음

###### 3. 프롬프트 작성의 전략적 접근
처음부터 복잡한 명령어보다는 아무 예시 없는 제로 샷 지시부터 시작
결과물을 보면서 점차 구체화하는 방식 권장
모호 미사여구 제거(ex. "너무 길지 않게")
금지어("~하지 마라") 대신 긍정형 지시문("~하라") 사용
(이 부분은 예전과 달라진 부분.. Codex는 주의사항같은 금지사항 명시해주면 더 잘한다며..)

###### 4. 복잡한 논리적 추론에는 생각할 시간 부여
"단계별로 생각하라"는 지시를 통해 AI가 스스로 오류 점검 및 결론을 도출하도록 만드는 방식

### Document Skill
pdf - pdf 파일을 구조화된 데이터로 읽고 쓴다.
doc - doc 파일을 구조화된 데이터로 읽고 쓴다.
spreadsheet - 엑셀 파일을 구조화된 데이터로 읽고 쓴다.

```
// 예시
$pdf sn74hc595.pdf 를 분석해서 $doc docs파일에 한글로 요약정리해줘
$spreadsheet 유형검사.xlsx 읽고 점수 계산하는 로직과 점수에 따른 유형 $doc 에 정리해줘
```


### Notion Skill
notion-knowledge-capture
: 대화나 문서에서 핵심 인사이트를 추출해 Notion에 구조화하여 작성한다.
notion-research-documentation
: 조사 결과를 정리해 Notion에 구조화하여 작성한다.
notion-meeting-notes
: 내용을 논의/결정/액션 아이템 기준으로 정리해 Notion 회의록 템플릿으로 구조화하여 작성한다.
