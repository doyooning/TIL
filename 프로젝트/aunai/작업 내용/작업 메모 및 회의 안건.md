## 작업 내용 중 공유사항:

### 인연 목록 doorPreview.signs — 저장된 표지판 좌표 반영
- **앱의 드래그 상한 반영** — 앱이 orb 를 `dx`/`dy` 0.95 까지만 놓을 수 있게 막아 주세요. 지금은 그 너머로 끌어 놓으면 저장 시점에 400 이 나 사용자가 이유를 알 수 없습니다.
- **포스트잇의 반쪽 좌표** — `postit` 쪽 `PositionRequest` 도 Patch 그룹에 `@NotNull` 이 없어 `dx` 만 보내는 요청이 통과합니다. 범위 밖이라 두었습니다.
- **`assetIds` 로 첨부를 비우는 방법이 없음** — `SecretService.patchSecrets` 는 `assetIds` 가 비어 있으면 건너뛰므로, 첨부를 전부 지우는 PATCH 는 지금 불가능합니다. 이번 버그와 무관해 두었습니다.


### PATCH /api/secrets — 비밀 orb 위치 수정 미반영 버그 수정 (구현 결과)
-  앱 팀 확인 요청
  `x`/`y` 만 읽는 경로가 남아 있으면 좌표가 통째로 빕니다. 요청서에 `PlacedSignItem` 은 둘 다 파싱한다고 되어 있었는데, **`currentHandle` 을 읽는 쪽도 같은지** 배포 전에 봐 주세요.


### AdMob SSV 연동 및 전단지 삭제 API 보상형 광고 검증 (Phase 2a)
요청서와 다르게 한 것 중 봐주실 것
- **검증 순서를 바꿨습니다.** 서명 → 본인 → 대상 전단지 → 이미 사용. 본인 확인을 사용 여부보다 먼저 봐야, 남의 `transaction_id`를 넣어 본 사람에게 "그 리워드는 이미 쓰였다"를 알려 주지 않습니다.
- **서명 실패 콜백은 저장하지 않습니다.** 인증 없는 경로라 실패까지 남기면 누구나 표를 무한히 불릴 수 있습니다. `signature_verified` 컬럼은 남겨 삭제 가드가 기록으로 읽게 했습니다.
- **공개키 조회 실패는 `AD-010`이 아니라 5xx입니다.** "서명이 틀렸다"와 "판정할 수 없었다"를 같게 다루면 네트워크가 잠깐 끊긴 사이의 정상 콜백이 위조로 기록됩니다.
- **`login_user_id`를 nullable로** 했습니다. Google은 앱이 준 문자열을 그대로 돌려주므로 탈퇴 사용자나 비-UUID가 옵니다. 거절하면 Google이 영영 재시도하고 기록도 없어서, 비운 채 행만 남깁니다(그 리워드는 `AD-007`에서 걸립니다).

요청서가 지적한 **`DoorAdFacade`의 `rewardedAdCompleted` 미전달 버그**도 함께 고쳤습니다 — 명령을 풀어 넘기던 것을 통째로 전달하도록 시그니처를 바꿨습니다.

⚠️ 배포 순서 주의
- `omnibus.ad.ssv.required` 기본값이 `true`라, **앱 배포보다 먼저 나가면 구버전 앱의 전단지 삭제가 전부 `AD-005`로 막힙니다.** 서버 배포 시 `OMNIBUS_AD_SSV_REQUIRED=false` → AdMob 콘솔 등록 → 콜백 수신 확인 → 앱 배포 → 플래그 제거 순입니다.

남은 것
- 소비되지 않은 리워드(`consumed_at IS NULL`)가 계속 쌓입니다. 광고만 보고 삭제하지 않은 경우인데, 리워드 유효기간이 정책 결정이라 정리 배치는 넣지 않았습니다.
