• 프로젝트 개요
  Spring Boot 3.5.13 + Java 21 기반의 Gradle 멀티모듈 백엔드입니다. 루트 프로젝트명은 omnibus이고, 모듈 구성은 settings.gradle:1에 정의돼 있습니다. Docker Compose 기준 
  로컬 구성은 API, MySQL, Redis, MinIO를 함께 띄우는 형태입니다. README.md:17

  큰 구조

  - bootstrap: 실제 실행 애플리케이션. monolith-launcher, account-launcher, seed-launcher 3개가 있음.
  - api: Controller, request/response DTO, Swagger 인터페이스 계층.
  - service: UseCase, Facade, 애플리케이션 서비스 계층.
  - domain: 도메인 모델, 포트, 도메인 서비스, 예외.
  - data: JPA/Redis 어댑터, repository, mapper 등 persistence 구현.
  - core: 공통 응답, 예외, 인증 resolver, validator, web config.
  - client: 외부 연동 클라이언트. http, s3, nice.
  - security: 모놀리스 보안 설정, 인증 필터, 세션/Redis 보안 연동.
  - event, worker: 이벤트 발행과 asset 관련 비동기/워커 처리.
  - test-support: test fixtures 전용 모듈.

  실행 단위

  - monolith-launcher가 메인 API 서버이며 omnibus.jar를 생성합니다. 앱 API, 계정 blocking API, 인증 API, 보안 모듈을 묶습니다. bootstrap/monolith-launcher/
    build.gradle:7

  - account-launcher는 omnibus-account.jar를 생성하며 WebFlux 기반 reactive 계정 API만 띄웁니다. bootstrap/account-launcher/build.gradle:5
  - seed-launcher는 omnibus-seed.jar를 생성하며 초기 이미지/도메인 데이터를 넣는 일회성 실행 모듈입니다. bootstrap/seed-launcher/build.gradle:5

  아키텍처 흐름
  요청 흐름은 대체로 api -> service -> domain port -> data/client입니다. 예를 들어 api:app-api는 controller와 DTO를 갖고, service:api-service, data:data-jpa,
  domain:api-domain, core:*, worker:asset-worker에 의존합니다. service:api-service는 usecase/facade에서 도메인과 data/client/event를 조합합니다.

  기술 요소

  - Java 21, Spring Boot 3.5.13, Gradle 멀티모듈. build.gradle:6
  - 모든 하위 모듈에 기본 Spring Boot starter, JUnit, Lombok, Spotless 적용. build.gradle:46
  - core:common-core는 거의 모든 모듈에 공통 의존성으로 자동 추가됩니다. build.gradle:102
  - API 모듈에는 REST Docs/Asciidoctor 설정이 자동 적용됩니다. build.gradle:97
  - DB는 MySQL 운영 기준, 테스트는 H2 MySQL mode 설정이 있습니다. data/data-jpa/src/main/resources/application-test.yml:1

  운영/문서

  - 로컬 포트는 API 8808, MySQL 3306, Redis 6379, MinIO 8091/8092입니다. README.md:21
  - Dockerfile은 .docker/api, .docker/account에 있고, 배포/Nginx 스크립트는 .deploy, Prometheus 설정은 .infra에 있습니다.
  - API 문서는 docs/api/app-api/api 명세서.html, 에러 코드는 docs/ERROR_CODE_SPECIFICATION.md에 있습니다.

  전체적으로 “도메인/서비스/API/인프라 어댑터를 분리한 Spring 멀티모듈 모놀리스”이고, 계정 인증 일부는 blocking/reactive 버전을 병행하는 과도기적 구조로 보입니다.
