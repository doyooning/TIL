# 기능 흐름

곡명 입력 → 유튜브 자동 검색 (API) → 악보바다 검색 링크 자동 생성 → 사용자가 악보 있음/없음 체크 → 세션 구성 입력 → 커뮤니티에 업로드 → 투표


# 기술 스택

| 항목     | 해당 기술                    |
| ------ | ------------------------ |
| DB/백엔드 | Supabase (PostgreSQL)    |
| 인증     | Supabase Auth            |
| 배포     | Vercel (Supabase와 궁합 좋음) |
| 프론트엔드  | React (Vite) 또는 Vue.js   |
| 유튜브 연동 | YouTube Data API v3      |
