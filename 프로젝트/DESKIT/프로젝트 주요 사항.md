# 주요 문제 해결
### **JPA N+1 문제**
요약하면, 이 프로젝트는 상품 목록 조회에서 연관 엔티티를 개별로 지연로딩하지 않고, 
필요한 데이터만 “배치 조회 + DTO 조합”으로 N+1을 피합니다. 
그리고 전역적으로 Hibernate batch fetch size도 설정되어 있습니다.

핵심 대응 방식 (상품 조회 기준)

  1. 상품 목록 조회 시 태그를 한 번에 배치 조회
     `ProductService.getProducts()`에서 상품 목록을 먼저 가져온 다음,  상품 ID 리스트로 태그를 IN 쿼리로 한 번에 조회합니다.                                                                                                           
     이때 `ProductTagRepository.findActiveTagsByProductIds(...)`는 projection 쿼리로 필요한 컬럼만 조회해 DTO로 조합합니다.                                                                                                           
     파일: `src/main/java/com/deskit/deskit/product/service/ProductService.java`
     파일: `src/main/java/com/deskit/deskit/product/repository/ProductTagRepository.java`                                                                                                                                            
  2. 썸네일/이미지, 라이브 가격도 배치 조회
     같은 `getProducts()`에서 이미지와 라이브 가격도 productIds로 한 번에 조회하고, 결과를 맵으로 묶어 응답 DTO에 조합합니다.
	  
  3. Hibernate batch fetch size 설정
     전역적으로 `hibernate.default_batch_fetch_size=100`이 설정되어 있어, LAZY 연관 로딩이 발생하더라도 묶음으로 가져오는 힌트가 제공됩니다.
     파일: `src/main/resources/application.properties`


아래는 상품 목록 조회(getProducts) 기준으로 실제 나가는 쿼리 흐름을 단계별로 정리한 것입니다. 
단건 조회(getProduct)는 별도 섹션에 덧붙입니다.

###### 상품 목록 조회 흐름 (ProductService.getProducts)

  1. 상품 기본 목록 조회
      - 목적: 삭제되지 않았고 판매중인 상품만 가져옴
      - 쿼리 형태:
```sql
		select *
		from Product
		where status = 'ON_SALE'
		order by id asc
```
        
      - 파일: src/main/java/com/deskit/deskit/product/service/ProductService.java
      
  2. 썸네일 이미지 일괄 조회
      - 목적: 상품별 썸네일(슬롯 0)만 한 번에 조회
      - 쿼리 형태:
```sql
        select *
        from ProductImage
        where product_id in ( ...productIds... )
            and image_type = 'THUMBNAIL'
            and slot_index = 0
        order by product_id asc, id asc
```
		
      - 파일: src/main/java/com/deskit/deskit/product/service/ProductService.java
      
  3. 라이브 가격 일괄 조회
      - 목적: 방송 중 상품의 현재 가격 오버라이드 조회
      - 쿼리 형태(개념적으로):
```sql
        select product_id, bp_price
        from BroadcastProduct
        and (라이브 상태 조건...)
```
		
      - 파일: src/main/java/com/deskit/deskit/product/service/ProductService.java
    
  4. 상품 태그 일괄 조회 (N+1 방지 핵심)
      - 목적: 상품별 태그를 한 번에 가져와 DTO로 조립
      - 쿼리 형태:
```sql
	    select pt.product.id as productId,
               tc.tagCode as tagCode,
               t.tagName as tagName
        from ProductTag pt
        join pt.tag t
        join t.tagCategory tc
        where pt.deletedAt is null
           and t.deletedAt is null
           and tc.deletedAt is null
           and pt.product.id in ( ...productIds... )
        order by pt.product.id, tc.tagCode, t.tagName
```

  5. 메모리에서 DTO 조합
      - 쿼리 없음 (메모리 처리)
  
###### 상품 단건 조회 흐름 (ProductService.getProduct)

  1. 상품 단건 조회
```sql
     select *
       from Product
        and status = 'ON_SALE'
        and deleted_at is null
```
	
     파일: src/main/java/com/deskit/deskit/product/service/ProductService.java
     파일: src/main/java/com/deskit/deskit/product/service/ProductService.java

  2. 태그 일괄 조회 (단건도 동일 로직 재사용)
```sql
     select pt.product.id as productId,
            tc.tagCode as tagCode,
            t.tagName as tagName
       from ProductTag pt
       join pt.tag t
       join t.tagCategory tc
      where pt.deletedAt is null
        and t.deletedAt is null
        and pt.product.id in ( ? )
      order by pt.product.id, tc.tagCode, t.tagName
```
	
     파일: src/main/java/com/deskit/deskit/product/repository/ProductTagRepository.java
    
  3. 썸네일/갤러리 이미지 조회 (단건)
```sql
     select *
       from ProductImage
      where product_id = ?
        and image_type = 'THUMBNAIL'
        and slot_index = 0
        and deleted_at is null
      order by id asc
     select *
       from ProductImage
        and deleted_at is null
      order by slot_index asc
```
	
     파일: src/main/java/com/deskit/deskit/product/service/ProductService.java

  4. 라이브 가격 단건 조회
```sql
       from BroadcastProduct
      where product_id = ?
        and (라이브 상태 조건...)
```
	
     파일: src/main/java/com/deskit/deskit/product/service/ProductService.java
