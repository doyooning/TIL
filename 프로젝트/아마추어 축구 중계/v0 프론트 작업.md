# 작업 구상도
v0가 초안을 만들면 여기에 기술한 대로 수정해서 완성해야 함

## 0. 로그인 페이지
`/login`
로그인 폼

`/signin`
회원가입

생각해봐야 할 점은
차피 유튜브 라이브 시청은 로그인 안해도 누구나 시청할 수 있고
채팅치려면 아마 유튜브에 로그인해야 할 것이라
앱 자체 로그인 기능이 필요한지?

## 1. 사용자 화면
`/`
사용자 메인 화면

`/match`
경기 목록

`/match/[id]`
경기 정보(라이브 화면)

## 2. 운영자 화면
`/admin`
운영자 메인 화면(대시보드)

`/admin/match/[id]`
운영자가 생성한 경기 관리
