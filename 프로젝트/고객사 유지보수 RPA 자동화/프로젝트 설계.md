```
IXP
 │
 │ 문서/메일 이해
 ▼
Agent
 │
 │ 판단
 ▼
Maestro
 │
 │ 프로세스 orchestration
 ▼
RPA / API / Human
 │
 ▼
실제 업무 수행
```


# 프로세스 흐름도
```
고객 문의 메일
      ↓
IXP
 ├─ 고객사
 ├─ 장애 유형
 ├─ 긴급도
 ├─ 오류 메시지
 └─ 요청 내용
      ↓
AI Agent
 "어떤 장애인가?"
 "기존 해결 사례가 있는가?"
 "자동 대응 가능한가?"
      ↓
Maestro
      ↓
 ┌───────────────┐
자동 처리       담당자 처리
 │                 │
Robot/API       Action Center
```
